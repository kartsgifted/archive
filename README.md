[K예술영재 프로젝트 통합 워크숍 아카이브 - 사용 안내]

파일 구성
- index.html : 방문자가 보는 공개 아카이브 사이트
- admin.html : 관리자 편집 페이지 (기본 비밀번호: karts2026)

기본 운영 방법
1. admin.html 을 열고 비밀번호로 접속합니다.
2. 좌측 메뉴에서 기본정보 / 분야 / 메뉴 / 회차 / 공지·업데이트·자료를 편집합니다.
3. 상단 "임시저장" → 같은 브라우저에서 index.html 을 열면 바로 미리보기 가능 (다른 사람에겐 아직 비공개).
4. "사이트 미리보기" 버튼으로 새 탭에서 바로 확인 가능.
5. 확정되면 "내보내기(data.json)" → 다운로드된 data.json 을 index.html/admin.html 과 같은 폴더(저장소)에 업로드하면 모든 방문자에게 반영됩니다.
6. admin.html 안의 ADMIN_PASS 상수를 원하는 비밀번호로 바꿔서 사용하세요.

히어로 배경 동영상
- "기본 정보" 탭 > "히어로 배경 동영상"에서 설정합니다.
- 방식 1) 외부 URL (권장) : 아래 세 가지를 모두 자동 인식합니다.
    · 유튜브 링크 (watch?v=, youtu.be/, shorts/ 등 어떤 형태든 가능)
    · Vimeo 링크 (vimeo.com/영상ID)
    · mp4 등 직접 동영상 파일 링크
  붙여넣으면 자동으로 무음·자동재생·반복·컨트롤 숨김 배경으로 전환되고,
  관리자 페이지에 바로 작은 미리보기가 표시됩니다.
- 방식 2) 파일 업로드 : 로컬 동영상 파일을 선택하면 파일 자체를 데이터에 인코딩해 저장합니다.
  10MB 이하의 짧은 클립을 권장합니다. 큰 파일은 임시저장/내보내기가 느려지거나
  브라우저 저장 용량 제한으로 실패할 수 있습니다 — 이 경우 방식 1(URL)을 사용하세요.
- "배경 동영상 제거" 버튼으로 언제든 원래 그래픽 배경으로 되돌릴 수 있습니다.
- 동영상이 없을 때는 기존처럼 그래픽 배경이 표시됩니다.

주의
- GitHub Pages는 정적 호스팅이라 admin.html 에서 편집한 내용이 자동으로 실시간 반영되지는 않습니다.
  반드시 5번 단계(data.json 업로드)를 거쳐야 실제 방문자에게 보입니다.
- 유튜브/Vimeo 배경 재생은 각 플랫폼의 iframe 임베드 정책을 따르므로, 브라우저의 자동재생 차단
  설정에 따라 첫 로드 시 재생이 지연될 수 있습니다(음소거 상태이므로 대부분 자동재생됩니다).
- 실시간 자동 반영 및 대용량 동영상 관리가 필요하면 Google Apps Script + 구글시트(또는 구글드라이브)
  백엔드로 업그레이드할 수 있습니다 (기존 운영대시보드/주간업무 시스템과 동일한 방식).

풀페이지 스크롤 (신규)
- 메인 페이지가 bafeko.com처럼 3개의 풀스크린 섹션으로 나뉘어 있습니다.
  1) 히어로 ("네 개의 재능, 다섯 번의 만남")
  2) 회차별 워크숍 기록 (분야 필터 + 카드)
  3) 하단 (공지사항·최근 업데이트·자료실 + 푸터/오시는 길)
- 마우스 휠, 트랙패드, 우측 점(dot) 내비게이션 클릭 모두로 섹션 간 이동이 가능합니다.
- 회차 카드나 컨텐츠가 화면보다 많아지는 경우, 해당 섹션 안에서는 자연스럽게
  더 스크롤한 뒤 다음 섹션으로 넘어갑니다(내용이 잘리지 않습니다).
- 회차 상세 페이지(#/session/N)는 기존처럼 일반 스크롤 페이지로 유지됩니다.
