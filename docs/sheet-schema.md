# 자료 관리 시트 명세

> Google Sheets 8개 탭. 공유하지 않으며 관문을 통해서만 접근한다.

---

## 1. 확정 사항

| 항목 | 규칙 |
|---|---|
| 탭 | 읽어보기 · 일정 · 자료 · 출석부 · 참여자 · 코드 · 설정 · 로그 |
| 세션ID | 자동 생성 (직접 입력 금지) |
| 공개여부 | 검수대기(기본) / 공개 / 비공개 |
| 자료 유형 | 영상 · 사진 · 사진묶음 · 작품(영상) · 작품(이미지) |
| 묶는 기준 | 워크숍 일자×시간 / 멘토링 분야×권역×회차 / 캠프 일자 |
| 접근코드 | `KA-MUSIC-7Q4F` 형식, 5종, 모두 전체 열람 |
| 파일명 | `20261015_1330_음악_A.mp4` |
| 메뉴 | 세션ID 생성 · 출석부 변환 · 영상 매칭 · 점검 |

---

## 2. 탭 구성

| 탭 | 입력 | 역할 |
|---|---|---|
| 읽어보기 | 안내 | 입력 규칙과 자료 유형 설명 |
| 일정 | 직접 | 수업 한 칸이 한 줄. 세션ID는 자동 생성 |
| 자료 | 직접 | 영상·사진 한 건이 한 줄. 세션ID로 일정과 연결 |
| 출석부 | 직접 | 가로 수업 × 세로 성명 |
| 참여자 | **자동** | 출석부에서 변환. 성명 검색의 근거 |
| 코드 | 직접 | 접근코드·사용기한·버전 |
| 설정 | 직접 | 영상 서비스, 안내 문구 등 운영 값 |
| 로그 | **자동** | 로그인·자료 요청 기록 |

---

## 3. 탭별 열 구성

### 3-1. 읽어보기

표 형식 열 구성 없음. 자유 서식 안내문(입력 규칙, 자료 유형 설명, 예시)을 적는다.

### 3-2. 일정

수업 한 칸이 한 줄. 자동 생성·잠금 열은 별도 표기.

| 열 | 입력 | 비고 |
|---|---|---|
| 세션ID | 자동 · 잠금 | [세션ID 생성] 메뉴로 부여. 직접 입력 금지 |
| 프로그램 | 선택 목록 | 워크숍 · 심화 멘토링 · 겨울 심화캠프 |
| 분야 | 선택 목록 | 음악 · 무용 · 전통예술 · 미술 |
| 일자 | 직접 | |
| 시작시각 | 직접 | |
| 종료시각 | 직접 | 시작·종료 두 열로 분리(기존 코드의 EN DASH 전용 분리 방식은 가져오지 않음) |
| 권역 | 직접 | 심화 멘토링만 사용 |
| 회차 | 직접 | 심화 멘토링만 사용 |
| 수업명 | 직접 | 일정표·목록 화면 제목 |
| 강사명 | 직접 | 일정표·자료 상세에 담당 강사 표시용 |
| 비고 | 직접 | |

> 묶는 기준(워크숍=일자×시간대 / 멘토링=분야×권역×회차 / 캠프=일자)은 `docs/sheet-schema.md` 7절 참조.

### 3-3. 자료

영상·사진 한 건이 한 줄. 세션ID로 「일정」과 연결한다.

| 열 | 입력 | 비고 |
|---|---|---|
| 세션ID | 직접 | 「일정」 탭 값 선택. **학생 작품은 비움** |
| 자료유형 | 선택 목록 | 영상 · 사진 · 사진묶음 · 작품(영상) · 작품(이미지) |
| 파일명 | 직접 | 영상은 `20261015_1330_음악_A.mp4` 규칙 적용. 로그 탭의 "대상 자료"는 이 값으로 식별 |
| 링크 | 직접 | Vimeo ID 또는 Drive 파일 ID |
| 공개여부 | 선택 목록 | 검수대기(기본) · 공개 · 비공개 |
| 규격 | 직접 | 사진묶음의 전체 장수 등 |
| 학생명 | 직접 | **작품(영상)·작품(이미지)일 때만 기재** |
| 분야 | 직접 | **작품일 때만 기재** (세션ID가 없어 일정에서 분야를 유추할 수 없음). 일반 자료는 세션ID로 분야를 알 수 있어 비움 |
| 비고 | 직접 | |

### 3-4. 출석부

고정 열 구성이 아니라 **가로 = 수업, 세로 = 성명인 행렬**. 담당자가 기존에 쓰던 출석부 형태 그대로 입력하면 [출석부 변환] 메뉴가 「참여자」 탭으로 바꾼다.

| 구성 | 내용 |
|---|---|
| 첫 행 | 수업(세션ID 또는 수업명) 나열 |
| 첫 열 | 학생 성명 |
| 교차 칸 | 출석 표시(예: 출석 시 체크, 결석 시 공란) |

> 정확한 표시 기호·양식은 기존에 쓰던 출석부 파일을 확인 후 맞춘다. **확인 필요**

### 3-5. 참여자 (자동)

「출석부」에서 변환되며 잠금. 성명 검색의 근거가 되는 탭이므로 (성명 × 참여 세션) 조합마다 한 줄.

| 열 | 비고 |
|---|---|
| 성명 | |
| 세션ID | 「일정」 탭과 연결. 여기서 분야·프로그램·일자를 조인해 화면에 표시 |

### 3-6. 코드

| 열 | 비고 |
|---|---|
| 코드 | `KA-MUSIC-7Q4F` 형식 |
| 이름 | 배포 대상 설명용 라벨 |
| 배포 대상 | 운영진 · 분야별(음악/무용/전통예술/미술) |
| 첫 화면 | 로그인 직후 진입할 분야·화면 |
| 사용기한 | 운영진 2027-03-31 / 분야별 교강사 2027-02-28 |
| 상태 | 사용 · 정지 등 |
| 버전 | 값을 올리면 해당 코드의 모든 접속이 즉시 해제됨 |
| 비고 | |

| 값 | |

고정값 항목에는 선택 목록을 적용한다. 표기가 흔들리면 화면에서 자료가 묶이지 않기 때문이다.

| 항목 | 목록 | 사용 탭 |
|---|---|---|
| 분야 | 음악 · 무용 · 전통예술 · 미술 | 일정 · 자료(작품) |
| 프로그램 | 워크숍 · 심화 멘토링 · 겨울 심화캠프 | 일정 |
| 자료 유형 | 영상 · 사진 · 사진묶음 · 작품(영상) · 작품(이미지) | 자료 |
| 공개여부 | 검수대기 · 공개 · 비공개 | 자료 |

## 5. 자료 유형

| 유형 | 내용 |
|---|---|
| 영상 | 수업 영상 |
| 사진 | 대표 사진 한 장. 화면에 직접 표시 |
| 사진묶음 | 전체 사진 폴더 링크. 규격 칸에 전체 장수 기재 |
| 작품(영상) | 학생 작품. 세션ID를 비우고 학생명과 분야를 기재 |
| 작품(이미지) | 위와 같음 |

대표 사진은 한 수업당 5~8장만 화면에 직접 표시하고, 전체는 폴더로 연결한다.

> **확인 필요** — 구글 로그인을 쓰지 않기로 하여 전체 사진 폴더의 열람 방법이 아직 정해지지 않았다. (`docs/decisions.md` 9절)

## 6. 공개여부

| 값 | 의미 |
|---|---|
| 검수대기 | **기본값.** 행을 추가하면 이 상태가 된다 |
| 공개 | 사이트에 내보낸다. **관문은 이 값만 내보낸다** |
| 비공개 | 사이트에 내보내지 않는다 |

---

## 7. 세션ID

- 분야·일자·시간대를 입력하면 **자동 생성**된다 ([세션ID 생성] 메뉴, 10절).
- **직접 입력하지 않는다.** 수기 입력 시 오타 한 글자로 영상이 연결되지 않는다.
- 「자료」 탭은 세션ID로 「일정」 탭과 연결된다.

**형식** (분야코드: 음악 music · 무용 dance · 전통예술 trad · 미술 art)

| 프로그램 | 형식 | 예 |
|---|---|---|
| 워크숍 | `{분야코드}-{MMDD}-{순번}` | `music-0807-1` |
| 심화 멘토링 | `{분야코드}-{권역}-{회차}` | `music-광주-1` |
| 겨울 심화캠프 | `{분야코드}-camp-{MMDD}-{순번}` | `music-camp-0115-1` |

이미 세션ID가 있는 행은 다시 만들지 않는다. 행을 지웠다 새로 추가하면 순번이 꼬일 수 있어 [점검] 메뉴로 중복을 확인한다.

### 묶는 기준

| 프로그램 | 기준 |
|---|---|
| 워크숍 | 일자 × 시간대 |
| 심화 멘토링 | 분야 × 권역 × 회차 |
| 겨울 심화캠프 | 일자 |
| 학생 작품 | 시간대에 귀속되지 않음. 학생 · 분야 단위 |

## 8. 접근코드

| 항목 | 규칙 |
|---|---|
| 형식 | `KA-MUSIC-7Q4F` — 앞부분은 배포 단위, 뒤 4자리 무작위 |
| 수 | 5종 (운영진 1 + 분야별 4: 음악·무용·전통예술·미술) |
| 열람 범위 | **모두 전체 열람.** 코드에 따라 첫 화면만 달라진다 |
| 사용기한 | 운영진 2027-03-31 / 분야별 교강사 2027-02-28 |
| 버전 | 값을 올리면 해당 코드의 모든 접속이 즉시 해제된다 |

> **실제 코드 값은 이 문서에 쓰지 않는다.** `docs/private/`에만 둔다.

## 10. 시트 메뉴

| 메뉴 | 동작 |
|---|---|
| 세션ID 생성 | 「일정」 탭의 새 행에 세션ID를 부여한다 |
| 출석부 변환 | 「출석부」 탭을 「참여자」 탭 형태로 변환한다 |
| 영상 매칭 | 파일명 규칙으로 영상과 세션을 연결한다 |
| 점검 | 빠진 값·중복·연결 안 된 자료를 찾아낸다 |

## 11. 보호 설정

| 대상 | 설정 |
|---|---|
