# 화면 흐름

> 화면 규칙의 근거는 `docs/decisions.md` 2·3절. 여기서는 6단계 각각의 상세와 전환 규칙을 정한다.
> 요청·응답 형태는 `docs/api.md`, 시트 열은 `docs/sheet-schema.md` 참조.

---

## 1. 6단계 흐름

```
로그인 → 분야 → 프로그램 → 일정표 → 목록 → 열람
```

| 단계 | 건너뛰는 경우 |
|---|---|
| 분야 | 분야 코드로 로그인하면 해당 분야로 바로 이동. 운영진(STAFF) 코드만 분야 선택 화면을 거침 |
| 프로그램 | 없음. 항상 워크숍 · 심화 멘토링 · 겨울 심화캠프 · 학생 작품 중 선택 |
| 일정표 | **학생 작품**은 시간대에 귀속되지 않으므로 일정표를 건너뛰고 목록으로 바로 이동 |

라우팅은 해시 방식: `#/music/workshop/세션ID` (`docs/decisions.md` 2절).

---

## 2. 로그인 화면

- 입력: 접근코드, 이름
- `auth` 요청 → 성공 시 토큰을 `sessionStorage`에 저장하고 곧바로 `data` 요청 1회 → 응답을 브라우저에 캐시
- 성공 후 「코드」 탭의 첫 화면 값에 따라 분야 화면 또는 해당 분야로 이동
- 실패 시 오류코드별 안내 문구 표시 (`AUTH_INVALID` · `AUTH_EXPIRED` · `AUTH_LOCKED`)
- 새로고침 시 세션 유지, 탭을 닫으면 해제 (`sessionStorage` 특성)

**재활용**: 기존 `index.html`의 `convertHangulToEnglish()` — 한영 전환 없이 입력된 접근코드를 되돌리는 보정. 접근코드 검증 로직 자체는 가져오지 않음(관문이 담당).

---

## 3. 분야 선택 화면

- 대상: 운영진 코드로 로그인한 경우만
- 4개 분야 카드: 음악 · 무용 · 전통예술 · 미술
- 분야 코드로 로그인한 이용자도 상단바를 통해 언제든 다른 분야로 이동 가능 (제한 없음, `docs/decisions.md` "분야 이동")

---

## 4. 프로그램 선택 화면

- 4개 카드: 워크숍 · 심화 멘토링 · 겨울 심화캠프 · 학생 작품
- 학생 작품 선택 시 일정표를 건너뛰고 목록 화면(작품 전용)으로 이동

---

## 5. 일정표 화면

프로그램마다 레이아웃이 다르다.

| 프로그램 | 형태 | 묶는 기준 |
|---|---|---|
| 워크숍 | 격자 (일자 × 시간대, 30분 슬롯 매트릭스, rowSpan) | 일자 × 시간대 |
| 심화 멘토링 | 격자 (권역 × 회차) | 분야 × 권역 × 회차 |
| 겨울 심화캠프 | 카드 (일자별) | 일자 |

- 자료를 보유한 칸은 강조 표시, 미보유 칸은 "자료 없음"이고 클릭해도 이동하지 않음
- 데이터는 `data` 응답의 `sessions` + `materials`를 세션ID로 대조해 보유 여부를 계산 (추가 요청 없음)

**재활용**: 기존 `index.html`의 `buildScheduleTable()` — 30분 슬롯 매트릭스 + rowSpan + sticky 헤더. 심화 멘토링 격자(권역×회차)는 기존 함수가 다루지 않는 새 구조라 별도 구현이 필요함. **확인 필요** — 심화 멘토링 격자의 정확한 배치(권역을 열로, 회차를 행으로 할지 등)는 실제 시범 데이터가 들어오면 확정.

---

## 6. 자료 목록 화면

- 선택한 세션ID(또는 학생 작품)에 속한 자료를 **영상 · 사진 · 작품** 탭으로 구분해 나열
- 한 시간대에 자료가 여러 건인 경우가 일반적(카메라 복수 운용, 녹화 분할, 사진 다수)이므로 이 단계를 반드시 거침 (`docs/decisions.md` 2절)
- 각 항목에 참여자 칩 표시 (「참여자」 탭에서 세션ID로 조회)

---

## 7. 열람 화면

| 자료유형 | 방식 |
|---|---|
| 영상 · 작품(영상) | 화면 안 재생(Vimeo). 사이트 밖에서 열리면 도메인 제한이 무력해지므로 새 탭으로 열지 않음 |
| 사진 · 작품(이미지) | 확대 보기. `photo` 요청으로 축소본을 받아 표시 |
| 참여자 칩 | 클릭 시 인물 상세 화면으로 이동 |

**재활용**: 기존 `index.html`의 영상 모달 — 닫을 때 iframe을 제거해 재생을 중단시키는 처리.

**금지**: 워터마크 표시, 영상 다운로드 버튼, 검색엔진 노출(전 화면 `noindex` 또는 `robots.txt` 차단).

---

## 8. 상시 검색

- 상단바에 항상 노출, 어느 단계에서도 검색 가능
- 대상: 분야 · 활동명 · 수업명 · 교강사 · 학생 · 장소
- 결과는 **사람 · 수업 · 작품**으로 구분해 표시 (한 번의 입력으로 전체를 조회하되 성격이 섞이지 않게 함)
- 인물 상세: 참여 이력(세션 목록) + 함께 참여한 인물
- 성명 검색은 접근코드 인증자에게만 제공. 홍보 사이트에는 어떤 형태로도 제공하지 않음

검색은 `data` 응답으로 받은 `sessions` · `materials` · `participants`를 브라우저에서 필터링해 처리하며, 추가 관문 요청을 만들지 않는다.

---

## 9. 공통 요소

- 상단바: 로고 · 경로 표시 · 통합검색 · 로그아웃 (모든 단계에 고정)
- 진입 화면(로그인 직후 또는 첫 방문 시)에 자료 외부 유출·재배포 금지 안내 표시
