# 관문 API 명세

> 관문 = Google Apps Script 웹앱. 열람 화면과 자료 관리 시트 사이에서 요청마다 권한을 확인한다.

---

## 1. 확정 사항

| 항목 | 규칙 |
|---|---|
| 응답 | JSON만, `{ ok, error, data }` 고정 |
| 요청 | auth(로그인) · ping(연장) · data(자료) · photo(사진) |
| 토큰 | 2시간, 사용 중 연장, 코드 `버전` 변경 시 전부 무효 |
| 실패 제한 | 기기별 5회 → 10분 잠금, 급증 시 운영진 메일 |
| 로그 | 모든 로그인·자료 요청 기록 |
| 영상 서비스 | 설정값으로 교체 가능 (기본 Vimeo) |

**보안 원칙** (`docs/decisions.md` 6절)

- 인증·토큰·공개여부·자료 허용 여부는 **모두 관문에서 매 요청 검증**한다.
- 공개여부가 `공개`인 자료만 내보낸다.
- 서명 키는 Script Properties에만 둔다. 토큰은 HMAC 서명하고 **요청 본문으로만** 전달한다(URL 금지).
- 관문은 HTML을 내보내지 않는다.
- 시트에 기록하는 값은 수식 주입을 막는다(`=` `+` `-` `@`로 시작하면 앞에 `'`).

---

## 2. 응답 형식

모든 응답은 아래 형태를 벗어나지 않는다.

```json
{ "ok": true,  "error": null,        "data": { } }
{ "ok": false, "error": "코드",       "data": null }
```

| 필드 | 형 | 설명 |
|---|---|---|
| `ok` | boolean | 성공 여부 |
| `error` | string \| null | 실패 시 오류 코드. 성공 시 `null` |
| `data` | object \| null | 성공 시 결과. 실패 시 `null` |

이 형식을 고정하는 이유는 나중에 관문을 다른 백엔드로 교체해도 화면 코드를 고치지 않기 위함이다.

---

## 3. 요청별 명세

| 요청 | 용도 |
|---|---|
| `auth` | 접근코드·이름으로 로그인하고 토큰을 받는다 |
| `ping` | 사용 중 토큰 유효시간을 연장한다 |
| `data` | 공개 자료를 받는다 |
| `photo` | 대표 사진 축소본을 받는다 |

모든 요청은 POST 본문에 `action` 필드로 종류를 담아 보낸다(토큰을 URL에 넣지 않기 위함, 6절 참조).

### 3-1. auth

로그인. 접근코드·이름·기기ID로 토큰을 받는다.

**요청**

| 필드 | 설명 |
|---|---|
| `action` | `"auth"` |
| `code` | 접근코드 (`KA-MUSIC-7Q4F` 형식) |
| `name` | 입력한 이름. 로그·기록용이며 별도 명단과 대조하지 않음 |
| `deviceId` | `localStorage`의 기기ID |

**응답 `data`**

| 필드 | 설명 |
|---|---|
| `token` | 서명된 토큰 |
| `expiresAt` | 만료 시각 (발급 시점 + 2시간) |
| `firstView` | 「코드」 탭의 "첫 화면" 값 (진입 시 이동할 분야·화면) |

**검증 순서**: 코드 존재 → 상태 "사용" → 사용기한 이내 → 기기별 실패 횟수(6절) → 통과 시 토큰 발급, 「로그」 기록.

### 3-2. ping

토큰 유효시간을 연장한다.

**요청**

| 필드 | 설명 |
|---|---|
| `action` | `"ping"` |
| `token` | 현재 토큰 |

**응답 `data`**

| 필드 | 설명 |
|---|---|
| `expiresAt` | 연장된 만료 시각 |

### 3-3. data

공개 자료를 **한 번에** 받는다. 인증 직후 1회 호출하고, 이후 화면 이동·검색은 이 응답을 브라우저에 캐시해 처리한다(요청 수를 줄여 실행 한도를 아끼기 위함, `docs/decisions.md` 2절).

**요청**

| 필드 | 설명 |
|---|---|
| `action` | `"data"` |
| `token` | 현재 토큰 |

**응답 `data`**

| 필드 | 내용 |
|---|---|
| `sessions` | 「일정」 탭 전체 (세션ID·프로그램·분야·일자·시작~종료시각·권역·회차·수업명·강사명) |
| `materials` | 「자료」 탭 중 **공개여부 = 공개**만 (세션ID·자료유형·파일명·링크·규격·학생명·분야) |
| `participants` | 「참여자」 탭 전체 (성명·세션ID) — 성명 검색용 |
| `settings` | 「설정」 탭 값 (영상 서비스 등) |

> 토큰이 유효한 이용자는 전체 열람 대상이므로(`docs/decisions.md` 8절) 분야별로 따로 나누어 내려주지 않는다.

### 3-4. photo

대표 사진 축소본을 받는다. 응답이 JSON만이므로(1절) 이미지는 base64로 담는다.

**요청**

| 필드 | 설명 |
|---|---|
| `action` | `"photo"` |
| `token` | 현재 토큰 |
| `fileId` | 「자료」 탭의 링크(Drive 파일 ID) |

**응답 `data`**

| 필드 | 설명 |
|---|---|
| `base64` | 이미지 데이터 |
| `mimeType` | 예: `image/jpeg` |

> 요청 시점에도 해당 자료의 공개여부를 다시 확인한다(요청마다 검증, `docs/decisions.md` 6절).

## 4. 오류 코드

| 코드 | 상황 |
|---|---|
| `AUTH_INVALID` | 접근코드가 존재하지 않거나 상태가 "사용"이 아님 |
| `AUTH_EXPIRED` | 접근코드 사용기한이 지남 |
| `AUTH_LOCKED` | 기기별 실패 5회로 10분 잠금 (6절) |
| `TOKEN_INVALID` | 토큰이 없거나 서명이 맞지 않음 |
| `TOKEN_EXPIRED` | 토큰 만료(2시간 경과 또는 코드 버전 변경으로 일괄 무효화) |
| `NOT_FOUND` | 요청한 자료가 없거나 공개여부가 "공개"가 아님 |
| `SERVER_ERROR` | 그 외 관문 내부 오류 |

## 5. 토큰

| 항목 | 규칙 | 이유 |
|---|---|---|
| 유효시간 | 서버 기준 2시간 | 방치된 세션은 만료시키되 열람 중에는 끊기지 않게 함 |
| 연장 | 사용 중 자동 연장 (`ping`) | 위와 같음 |
| 서명 | HMAC. 서명 키는 Script Properties에만 보관 | 주소·코드에서 키가 드러나지 않게 함 |
| 전달 | 요청 본문으로만. URL에 넣지 않는다 | 주소 기록·로그에 토큰이 남지 않게 함 |
| 보관 위치 | 화면 쪽 `sessionStorage` | 탭·브라우저를 닫으면 해제됨 |
| 일괄 무효화 | 시트 「코드」 탭의 **버전** 값을 올리면 해당 코드의 모든 접속이 즉시 해제됨 | 코드 유출 시 즉시 차단 수단이 필요함 |
| 장기 토큰 | 사용하지 않음 | 공용 PC에서 세션이 오래 남지 않게 함 |

---

## 6. 실패 제한

| 항목 | 규칙 |
|---|---|
| 기기별 | 5회 실패 시 10분 잠금 |
| 코드별 | 코드 앞부분(배포 단위) 기준 누적 제한 |
| 알림 | 실패가 급증하면 운영진에게 메일 |
| 기기ID | `localStorage`의 무작위 값. **인증 수단이 아니며** 실패 제한·로그 구분용으로만 쓴다 |

---

## 7. 로그

모든 **로그인**과 **자료 요청**을 시트 「로그」 탭에 기록한다.

기록 항목: 일시 · 결과 · 코드 · 이름 · 기기ID · 요청 · 대상 자료

열 구성 상세는 `docs/sheet-schema.md` 참조.

---

## 8. 영상 서비스 설정

영상 서비스는 시트 「설정」 탭의 값으로 선택한다. 기본값은 Vimeo이며, 관문과 화면은 서비스 이름을 직접 하드코딩하지 않는다.
